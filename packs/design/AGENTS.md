# Design pack

Frontend design and UI polish.

## Skills

- `impeccable` — design, redesign, critique, audit, polish, or improve any frontend interface. Runs critique loops with score records, and ships helper scripts under the skill's own `scripts/` folder.

Upstream updates: `packs/design/scripts/update-impeccable.sh` pulls the latest [pbakaus/impeccable](https://github.com/pbakaus/impeccable) into the skill and reapplies the workspace integration (run with `--dry-run` to preview).

See the skill's `SKILL.md` and `.workspace-integration.md` for the full workflow, integration points, and companion skills.
